# USK SCHOOLMONEY

ระบบหลังบ้านภาษาไทยสำหรับโรงเรียนอุทยานศึกษากระบี่ เวอร์ชัน 1.0.0

## สิ่งที่ส่งมอบ

HTML5, Tailwind CSS ที่คอมไพล์แล้ว, Vanilla JavaScript และ Node.js/Express API ใช้ Firebase Authentication และ Cloud Firestore สำหรับบัญชีและข้อมูล ใช้ Supabase Storage สำหรับไฟล์เท่านั้น ตามข้อกำหนดท้ายคำขอ ไม่มีการใส่นักเรียน ยอดเงิน หรือบัญชีทดลองลงฐานข้อมูล

ไฟล์ `public/index.html` เป็นหน้าจอเริ่มต้น ส่วน `USK-SCHOOLMONEY.html` รวม HTML, CSS และ JavaScript หน้าจอไว้ในไฟล์เดียว สามารถนำไปแทน `public/index.html` ได้ ทั้งสองแบบต้องทำงานผ่านเซิร์ฟเวอร์นี้เพื่อเข้าสู่ระบบและบันทึกข้อมูล การดับเบิลคลิกไฟล์ HTML ไม่ได้เปิดฐานข้อมูลหรือระบบหลังบ้าน

## เตรียมบริการ

1. ใช้ Node.js 22 ขึ้นไป
2. ใน Firebase โครงการ `schoolmonnyusk` เปิด Authentication แบบ Email/Password และสร้าง Cloud Firestore จากนั้นกำหนดโดเมนใช้งานใน Authorized domains
3. นำกฎ `firestore.rules` ไปใช้ใน Firestore เพื่อห้ามเข้าถึงโดยตรงจากเบราว์เซอร์ ทุกคำขอข้อมูลต้องผ่าน API ที่ตรวจ Firebase ID token และสิทธิ์ในเอกสารผู้ดูแล
4. สร้าง Firebase service account สำหรับเซิร์ฟเวอร์ เก็บ JSON ไว้นอกโฟลเดอร์ public และนอกระบบควบคุมเวอร์ชัน ตั้งค่าเส้นทางใน `GOOGLE_APPLICATION_CREDENTIALS`
5. ใน Supabase สร้าง bucket ชื่อ `schoolmoney-private` เป็น Private กำหนดขนาดไฟล์ไม่เกิน 8 MB และอนุญาต image/png, image/jpeg, application/pdf ไม่ต้องเปิดสิทธิ์อัปโหลดหรืออ่านไฟล์แก่บุคคลทั่วไป
6. เปลี่ยนคีย์ service_role ที่เคยส่งในบทสนทนา ใส่คีย์ใหม่เฉพาะใน `.env` ฝั่งเซิร์ฟเวอร์ โค้ดไม่บรรจุคีย์ที่มีสิทธิ์สูง URL ที่ใช้คือ `https://ihagihlmaquzaniegcfp.supabase.co` ไม่ใช่ URL `/rest/v1/` และไม่ต่อคีย์เข้ากับ URL
7. ไม่ต้องใช้ Supabase anon key ในหน้าจอ เพราะการอัปโหลดและสร้างลิงก์ไฟล์ทำผ่านเซิร์ฟเวอร์ที่ตรวจสิทธิ์แล้ว

## เริ่มใช้งาน

```bash
npm ci
cp .env.example .env
```

แก้ `.env` ให้ครบ ใส่อีเมล ชื่อ และรหัสผ่านจริงอย่างน้อย 12 ตัวอักษรสำหรับบัญชีหลักครั้งแรกใน BOOTSTRAP_EMAIL, BOOTSTRAP_NAME, BOOTSTRAP_PASSWORD แล้วรัน:

```bash
npm run bootstrap
npm start
```

เปิด `http://localhost:3000` เข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่เพิ่งสร้าง ช่องชื่อผู้ใช้งานใช้อีเมลตาม Firebase Authentication เมื่อสร้างบัญชีแรกแล้วให้ลบค่า BOOTSTRAP_PASSWORD ออกจาก `.env` สคริปต์ไม่ยอมสร้างบัญชีหลักซ้ำเมื่อมีระบบแล้ว

ในการใช้งานจริงต้องเปิด HTTPS และรัน Node.js ต่อเนื่อง เช่น เซิร์ฟเวอร์ส่วนตัวที่ใช้ตัวจัดการโปรเซส อย่านำเฉพาะ HTML ไปไว้บนโฮสต์ไฟล์นิ่งแล้วคาดว่า API จะทำงาน งานล่วงหน้าจะตรวจทุก 30 วินาที และทำรายการค้างเมื่อเปิดเซิร์ฟเวอร์กลับมา

## ลำดับการใช้งาน

1. บัญชีหลักบันทึกข้อมูลเอกสาร โลโก้ ที่อยู่ และระยะเวลาหมดอายุในเมนูการตั้งค่า
2. เพิ่มนักเรียน เลือกหนึ่งในหอพักทั้งสี่ ระบุระดับชั้นเองได้
3. ระบุปีการศึกษา ภาคเรียน และเดือนในตัวกรอง ปีการศึกษาเป็น พ.ศ. 4 หลัก ภาคเรียนเป็นตัวเลข 1–2 หลัก เดือนใช้ตัวเลือกเดือนของเบราว์เซอร์
4. ในหน้าตรวจสอบค่าใช้จ่าย เลือกนักเรียน แก้ยอดหรือสถานะ แล้วบันทึกและยืนยันในกล่องโต้ตอบ สามารถเลือกได้สูงสุด 100 รายการต่อครั้ง
5. อัปโหลดสลิปพร้อมเลือกนักเรียนในเมนูภาพรวมสลิป ระบบผูกสลิปกับปี ภาคเรียนและเดือนที่เลือก การอัปโหลดสลิปไม่เปลี่ยนสถานะการเงินอัตโนมัติ ต้องให้ผู้ดูแลตรวจและยืนยัน
6. รายงานรองรับพิมพ์ ส่งออก PNG และ PDF ใช้รูปหน้ารายงานใน PDF เพื่อคงตัวอักษรไทย จึงไม่ใช่ PDF ที่เลือกข้อความได้ รายงานยาวแบ่งเป็นหน้ารูปภาพ
7. งานล่วงหน้าสร้างยอดให้ทุกคนที่มีอยู่ขณะทำงาน ไม่ทับข้อมูลการเงินเดิม งานยังไม่รองรับแก้ไขหรือยกเลิกผ่านหน้าจอ
8. เพิ่มผู้ดูแลได้เฉพาะบัญชีหลัก รวมสูงสุด 10 บัญชี ใช้ธุรกรรมจำกัดจำนวนพร้อมกัน รองรับเพิ่มและแก้ไขสิทธิ์บัญชีเดิม โดยป้องกันการลดสิทธิ์บัญชีหลักคนสุดท้าย ยังไม่มีหน้าปิดบัญชี
9. ล้างประวัติต้องส่งคำขอ แล้วให้ผู้ดูแลคนอื่นเข้ามาพิจารณา คำขอถูกบันทึกถาวร เมื่อยอมรับจะลบเฉพาะประวัติถึงเวลาขอ ไม่ลบคำขออนุมัติและกิจกรรมใหม่ ถ้ามีผู้ดูแลเพียงคนเดียวจะไม่สามารถส่งคำขอล้างประวัติได้
10. ข้อความเป็นระบบสนทนาภายในหลังบ้าน มีการรับเรื่อง แนบเอกสาร ยอมรับ/ปฏิเสธ และตอบกลับ ผู้ดูแลบันทึกเรื่องที่ได้รับจากนักเรียน รุ่นนี้ไม่มีพอร์ทัลนักเรียนหรือบริการส่งข้อความภายนอก ใช้ปุ่มรีเฟรชเพื่อรับข้อความล่าสุด

## สิทธิ์และข้อกำหนดการทำงาน

ผู้ดูแลทั่วไปจัดการนักเรียน การเงิน สลิป ธนาคาร ประชาสัมพันธ์ ข้อความและคำถามได้ บัญชีหลักเพิ่มผู้ดูแล ตั้งค่าระบบ และสร้างงานล่วงหน้าได้ การเปลี่ยนบทบาทไม่เชื่อค่าจากหน้าเว็บ การเพิ่มบัญชีจำกัดจำนวนบนเซิร์ฟเวอร์

ไฟล์ส่วนตัวเปิดด้วยลิงก์อายุ 120 วินาที โลโก้หน้าเข้าสู่ระบบเปิดเผยได้เป็นเวลา 60 วินาทีตามคำขอ ข้อมูลแสดงบนหน้าจอถูกเข้ารหัส HTML ก่อนแทรก การลบนักเรียนที่มีประวัติการเงินถูกปฏิเสธ

หน้าสรุปนับต่อคนในช่วงเวลาที่เลือก โดยค้างชำระมีลำดับก่อนรอตรวจสอบ และชำระครบต้องมีรายการอย่างน้อยหนึ่งรายการที่ทุกยอดเป็นชำระแล้ว ผู้ไม่มีรายการเป็นยังไม่ถึงกำหนด ไม่ถือว่าชำระครบ

การหมดอายุเมื่อไม่มีการใช้งานเป็นการออกจากระบบฝั่งเบราว์เซอร์ แต่ละ API ตรวจ token และบัญชีที่ยังเปิดใช้งาน รุ่นนี้ยังไม่มี server-side idle session ledger สำหรับเพิกถอน token จากเวลาไม่ใช้งานโดยตรง

หน้าจอใช้คำภาษาไทย ยกเว้นชื่อระบบและเมนู DASHBOARDS สรุปข้อมูลซึ่งคงข้อความตามที่ขอ ไอคอนไม่ใช้อีโมจิ กล่องโต้ตอบใช้เฉพาะดูสลิป ยืนยันการเงิน ภาพต้อนรับ และอนุมัติล้างประวัติ การลบนักเรียนยืนยันในแถบภายในหน้า

## ตรวจสอบและพัฒนา

```bash
npm test
npm run test:ui
npm run build:css
```

ระบบใช้งานอินเทอร์เน็ตเพื่อโหลด Firebase SDK และเครื่องมือส่งออก หากต้องการเครือข่ายปิดให้จัดเก็บไฟล์พึ่งพาเหล่านี้บนเซิร์ฟเวอร์เอง Tailwind ถูกคอมไพล์ไว้แล้ว ไม่ใช้ Play CDN ในงานจริง ไม่เปิด Analytics อัตโนมัติ เพราะไม่จำเป็นต่อระบบการเงิน
